# LAB

### Trait
A `trait` is a collection of methods defined for an uknown type: `Self`. They can access other methods declared in the same trait.

- source: [Rust Docs](https://doc.rust-lang.org/rust-by-example/trait.html 'official resource')
- explore: [about_trait](./about_trait)

### Generic Data Types
We use generics to create definitions for items like function signature or structs, which we can then use with many concrete data types.

- source [Rust Docs](https://doc.rust-lang.org/book/ch10-01-syntax.html 'official resource')
- explore: [about_trait](./generic_types)
